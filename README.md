# Physio Wellness by Marshall — Web

Sitio web de Physio Wellness by Marshall: fisioterapia, wellness, strength y pilates en Sitges.

## 📋 Estructura del proyecto

```
physiowellness-web/
├── index.html              Home
├── src/
│   ├── pages/              Páginas internas (método, servicios, tarifas, contacto)
│   ├── components/         Componentes reutilizables (header, footer, nav, botones)
│   ├── content/            Datos editables (tarifas, condiciones, URL de reserva)
│   ├── css/                Estilos (sistema de diseño, componentes, responsive)
│   ├── js/                 JavaScript (interactividad, animaciones, forms)
│   └── assets/             Imágenes, fuentes, iconos
```

## 🚀 Cómo empezar

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/physiowellness-web.git
   cd physiowellness-web
   ```

2. **Abrir en el navegador:**
   - Abre `index.html` directamente en el navegador, o
   - Si tienes Python: `python3 -m http.server 8000`

3. **Editar archivos:**
   - Abre con tu editor favorito (VSCode, etc.)
   - Los cambios se ven en tiempo real al recargar el navegador

## 🎨 Sistema de diseño

- **Color primario:** #237369
- **Color de acento:** #269888
- **Tipografía:** Jost (Google Fonts)
- **Responsive:** Mobile First (breakpoints: 640px, 860px, 960px, 1100px)

## 🔧 Tecnología

- HTML5 + CSS3 (sin frameworks)
- JavaScript vanilla (sin dependencias)
- Imágenes optimizadas (WebP)
- SEO-friendly (meta tags, structured data)
